# Entrenamiento Clínico-IA

Simulador de casos clínicos de SkyNet Genesis. Página estática (GitHub Pages, carpeta `docs/`) con base de datos Neon (Neon Auth + Data API).
Los casos clínicos NO están en este repositorio: viven en la base de datos, que entrega cada caso solo a quien tiene acceso y sin la clave de calificación (el puntaje lo calcula la base).

- `docs/` — la app publicada en https://entrenamiento-clinico-ia.skynetgenesis.com (instalable en el celular)
- `correos/` y `.github/workflows/` — tareas de cada mañana: correos con Brevo y facturas con Factura-IA (secretos NEON_CORREO, BREVO_API_KEY y FACTURA_IA_LLAVE)
